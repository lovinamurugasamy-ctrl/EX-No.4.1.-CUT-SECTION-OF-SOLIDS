# EX No.4.1. CUT SECTION OF SOLIDS
## DATE:

## AIM
To create the solid model from given drawing and section the solid model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3.16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
Part 1 – Create the base plate
Step 1: Create a new design
1. Open Autodesk Fusion 360.
2. Click File → New Design.
3. Click Create Sketch.
4. Select the XY plane.
Step 2: Draw the base outline
1. Select Sketch → Slot → Center-to-Center Slot (or use Line and Arc tools).
2. Draw the elongated base shape with rounded ends.
3. Set the overall base length to 70 mm.
4. Set the width according to the drawing.
5. Click Finish Sketch.
Step 3: Extrude the base
1. Press E (Extrude).
2. Select the base profile.
3. Enter the base thickness of 6 mm.
4. Choose New Body.
5. Click OK.


![image](https://user-images.githubusercontent.com/113594316/198825274-c6a8d3ee-fb19-4641-b915-8d2e000c40a8.png)

Part 2 – Create the central cylindrical boss
Step 4: Draw the central circle
1. Click the top face of the base plate.
2. Select Create Sketch.
3. Choose Circle → Center Diameter Circle.
4. Draw a circle at the centre of the base.
5. Press D and set the diameter to 50 mm (Ø50).
6. Click Finish Sketch.
Step 5: Extrude the boss
1. Press E to open the Extrude command.
2. Select the Ø50 circle profile.
3. Enter the height so the total height from the bottom of the base is 28 mm.
4. Since the base is 6 mm thick, extrude the boss 22 mm above the base.
5. Set Operation to Join.
6. Click OK.

![image](https://user-images.githubusercontent.com/113594316/198825282-0d3de4b8-b6d9-446a-ae2a-461955057399.png)

Step 6: Create the centre hole
1. Select the top circular face of the boss.
2. Click Create Sketch.
3. Select Circle → Center Diameter Circle.
4. Draw a circle at the centre.
5. Set the diameter to 20 mm (Ø20).
6. Click Finish Sketch.
Step 7: Cut the centre hole
1. Press E (Extrude).
2. Select the Ø20 circle.
3. Set Operation to Cut.
4. Select Through All.
5. Click OK.
Step 8: Create the counterbore
1. Select the top face of the boss.
2. Click Create Sketch.
3. Draw another concentric circle at the centre.
4. Set the diameter to 30 mm (Ø30).
5. Click Finish Sketch.
6. Press E.
7. Select the ring-shaped area between Ø30 and Ø20.
8. Set Operation to Cut.
9. Enter the depth as 6 mm.
10. Click OK.
    

![image](https://user-images.githubusercontent.com/113594316/198825301-194365b4-69d2-42ad-8545-a68d3ca1f442.png)

Part 4 – Create the two mounting holes (Ø12)
Step 9: Draw the mounting holes
1. Select the top face of the base plate.
2. Click Create Sketch.
3. Select Circle → Center Diameter Circle.
4. Draw the first circle on the left side of the central boss.
5. Set its diameter to 12 mm (Ø12).
6. Draw the second circle on the right side.
7. Set its diameter to 12 mm (Ø12).
8. Position the hole centres 35 mm on either side of the central axis.
9. Click Finish Sketch.
Step 10: Cut the holes
1. Press E.
2. Select both Ø12 circle profiles.
3. Change Operation to Cut.
4. Set the extent to Through All.
5. Click OK.

![image](https://user-images.githubusercontent.com/113594316/198825314-b90f6aba-da26-4f0d-8d61-a03e8ad0d765.png)

Part 5 – Create the small side hole (Ø6)
Step 11: Draw the side hole
1. Rotate the model to the side view.
2. Select the vertical side face of the central boss.
3. Click Create Sketch.
4. Select Circle → Center Diameter Circle.
5. Draw a small circle on the side face.
6. Set the diameter to 6 mm (Ø6).
7. Position the hole according to the drawing.
8. Click Finish Sketch.
Step 12: Cut the side hole
1. Press E (Extrude).
2. Select the Ø6 circle profile.
3. Change the operation to Cut.
4. Set the cut distance as required by the drawing.
5. Click OK.

![image](https://user-images.githubusercontent.com/113594316/198825328-205fac21-1322-4d67-894b-6fd92e454e26.png)

Part 6 – Final finishing
Step 13: Check and save the model
1. Rotate the model to the isometric view using the ViewCube.
2. Check the base plate and rounded ends.
3. Check the Ø50 central boss.
4. Check the Ø20 centre hole.
5. Check the Ø30 counterbore with 6 mm depth.
6. Check both Ø12 mounting holes.
7. Check the Ø6 side hole.
8. Click File → Save and save the design.
